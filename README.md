# 鲸扫 jingsao 🐳🧹

让住在 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）里的鲸鱼娘，帮你把爆红的 C 盘收拾干净。

鲸扫是 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的分叉版本：桌宠本体（100 多段鲸鱼娘动画、桌面模式、对话、语音、余额、睡觉……）保留，在它上面新增了 **C 盘清理**，以及鲸鱼娘专属的清理动画。为了装得更快、用得更专心，去掉了原版的天气、「吃白饭」小游戏、表情包配图和待办。

## 一行安装

DSH 桌面应用：打开「插件 → 添加插件 → 安装第三方插件」，填：

```
github:aliangAI-Lab/jingsao
```

或者用命令行（`dsh web` 把 `desktop` 换成 `web`）：

```
dsh plugin --profile desktop add github:aliangAI-Lab/jingsao
```

装完**重开 DSH** 才生效。鲸鱼娘出现后，右键点她 →「清理C盘」，清理面板就会从她身边弹出来（网页里是浮层，桌面上是一个小窗）。也可以直接在对话里说「帮我清 C 盘」。

> 已经装了原版 dsh-pet 也没关系：鲸扫换了插件名、接口前缀和数据目录，两个可以同时装，只是会有两只宠物。想只留一只，在 DSH 插件页停用其中一个即可。

## C 盘清理能做什么

| 功能       | 做什么                                                                                                                                                                                                                          | 怎么保证不出事                                                                                                                                                                                                            |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 垃圾清理   | 临时文件、系统临时文件、显卡画面缓存、浏览器缓存、Windows 更新下载缓存、传递优化缓存、错误报告、崩溃转储、驱动解压目录、回收站、开发工具下载缓存等，按「应用程序 / 系统相关 / 缓存文件 / 临时文件 / 开发工具缓存 / 回收站」分组 | 每条规则只认自己的根目录（全部由环境变量推导），不跟随联接；删前逐个复核大小和修改时间；个人文件夹、聊天记录、`.ssh`、`.git`、`.env` 永远不碰；系统组件存储、旧系统备份、休眠文件、虚拟内存只报告大小，交给系统自带的方式 |
| 微信QQ专清 | 微信（新版 4.x 和旧版）、QQ（QQNT）、企业微信存下的缓存、图片、视频、表情、收发文件；可只清 N 天以前的                                                                                                                          | 聊天记录数据库、收藏、备份、企业微信微盘不在清单里；「收发的文件」默认不勾                                                                                                                                                |
| 重复文件   | 找出内容一模一样的文件（先比大小，再比开头结尾，最后比全文）                                                                                                                                                                    | 每组至少留一份，默认留最早的那份                                                                                                                                                                                          |
| 大文件搬家 | 把你自己文件夹里的大文件（安装包、压缩包、视频……）搬到别的盘                                                                                                                                                                    | 只扫你的文件夹，不进 AppData 和程序目录；搬完先核对内容一致再删原文件；有记录，随时搬回来                                                                                                                                 |
| 软件搬家   | 整个软件目录搬到别的盘，原位置留一个目录联接，软件照常打开                                                                                                                                                                      | 正在运行、带系统服务、驱动/运行库/系统组件一律不让搬；失败自动回滚；有记录，随时搬回来                                                                                                                                    |

**点「立即清理」就直接删除**（不进回收站、不进暂存区），删前对每个文件复核一遍（还在规则的目录里、不是联接、大小和修改时间没变），被占用或没权限的自动跳过。默认不勾的风险项（开发工具缓存、崩溃转储……）如果你自己勾了，面板会在原位再确认一次。系统目录下的项目（Windows\Temp、更新缓存等）整批弹一次管理员确认，拒绝就只清普通项目。每次清理按规则记一行审计日志（插件数据目录 `clean-log.jsonl`，保留 30 天，只记数量不记路径）。

从上个版本升级的用户：如果上次「放进暂存区」的文件还没彻底释放，面板顶部会提示一次，可以「彻底删除」或「原样放回」。

点完清理面板就自动关上，鲸鱼娘接着演：抬头张大嘴把垃圾「吸」进去（清得越多漩涡越大），清完打个饱嗝，再把 C 盘容量条推回去，告诉你吃掉了多少。出错或取消时她会叹气冒汗，右键 →「清理C盘」看详情。

### 明确不做的清理项

别的清理工具会做、但鲸扫判断有风险或不属于「垃圾」的，不做，代码里也加不进来（安全闸会拦下）：

- **不常用输入法**（删 `C:\Windows\IME` 下的韩文、繁体等输入法文件）：系统受保护文件，删了可能影响系统更新和系统文件检查。
- **Windows Defender 的扫描历史、保护历史、定义备份、病毒隔离文件**：安全软件自己管理的数据，有防篡改保护，隔离文件删了无法还原。
- **Installer 补丁缓存（`C:\Windows\Installer\$PatchCache$`）、`Package Cache` 目录**：删了以后卸载或修复 Office、VC 运行库等软件会要求安装包。
- **Windows 预读取文件（Prefetch）**：删了反而让开机和启动程序变慢，几乎不省空间。
- **字体缓存**：要停系统服务。
- **在整个 AppData 里递归删 `*.tmp`、`*.log`**：太宽，会误删正在使用的程序数据。
- **Cookies、最近打开的文件、浏览器历史**：属于隐私清理，不省空间。
- **「下载」文件夹**：用户自己的文件，交给「大文件搬家」处理。
- **各软件的「老版本备份」**：每个软件目录结构不同，没有可靠规则前不做。

对话里的 AI 只有两个只读工具（扫描、打开面板）：它能帮你看、帮你解释，但移动、删除、搬家永远只能由你在面板里亲手点。

## 开发

```
pnpm install
npm test          # 全部单元测试
npm run build     # 构建 lib/（github: 安装直接用仓库里的 lib/，改完源码要重新构建再提交）
```

测试里所有会改文件的流程都在环境变量 `JINGSAO_TEST_ROOT` 指定的非 C 盘临时目录里进行，配到 C 盘会直接报错。
